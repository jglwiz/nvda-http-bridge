NVDA HTTP Bridge

面向本地 CLI、自动化测试和 agent 的 NVDA 回环 HTTP 接口。项目、add-on ID、实现包和产物统一采用 NVDA HTTP Bridge / nvdaHttpBridge 命名。

严格协议

服务只监听 127.0.0.1:19281。业务接口统一位于 /v1，树根名称与参数、动作名和备份字段均只接受文档中的规范形式。

快速验证

curl.exe http://127.0.0.1:19281/health
curl.exe http://127.0.0.1:19281/v1/version
curl.exe http://127.0.0.1:19281/v1/capabilities
curl.exe http://127.0.0.1:19281/v1/objects/focus

所有接口都不要求凭据。服务只接受本机回环连接并检查 Host、浏览器来源和安全桌面状态；任何本机进程都能调用接口，请勿代理、转发或暴露该端口。

接口

方法路径用途
GET/health健康、运行时间和任务指标
GET/v1/version插件、协议、NVDA 与 Python 版本
GET/v1/capabilities限制、字段、动作和事件类型
GET/v1/objects/{focus|foreground|navigator|desktop}对象快照
GET/v1/objects/by-id/{objectId}读取当前 generation 中的对象
GET/v1/tree有界可访问性树
GET/v1/speech、/v1/log敏感历史
GET/v1/eventsSSE 事件流
GET/PATCH/v1/modes读取或修改当前上下文模式
GET/v1/text/{caret|selection}读取有界文本范围
GET/v1/{addons|global-plugins|drivers|diagnostics}只读运行清单与诊断
POST/v1/tree/exports创建异步 NDJSON 树导出
POST/v1/backups创建异步便携版备份
POST/v1/diagnostics/exports创建有界诊断 ZIP
POST/v1/actions/{action}执行白名单动作
POST/v1/lifecycle/restart响应完成后调度 NVDA 原生进程重启

有界树与导出

同步树默认深度 3、每个父节点 20 个子节点、总计 200 个节点和 500 ms。根对象只接受 focus、foreground、navigator、desktop。

curl.exe "http://127.0.0.1:19281/v1/tree?root=foreground&depth=6&maxChildren=100&maxNodes=800&timeoutMs=2500&format=flat"

超过同步上限时使用 POST /v1/tree/exports。通过 GET /v1/tree/exports/{jobId} 查询状态，GET /v1/tree/exports/{jobId}/data 下载，DELETE /v1/tree/exports/{jobId} 取消或清理。

备份

POST /v1/backups 的请求体必须且只能包含 {"targetPath":"D:\\backups"}。插件创建 D:\backups\nvda，拒绝覆盖现有目录，并排除旧版本遗留的凭据文件。状态响应以 backupPath 返回实际目录。

POST   /v1/backups
GET    /v1/backups/{jobId}
DELETE /v1/backups/{jobId}

删除或过期任务只清理任务状态，不删除已完成的备份。

动作

动作名只接受 speak、cancel-speech、gesture、focus、default-action、set-caret 和 set-selection，通用动作和 gesture 均不能触发生命周期操作。明确授权的重启使用专用 POST /v1/lifecycle/restart；原始 HTTP 返回 202 后才调度重启，CLI 通过 PID/启动时间变化确认完成。

Invoke-RestMethod -Method Post `
  -Uri http://127.0.0.1:19281/v1/actions/speak `
  -ContentType application/json `
  -Body '{"text":"任务完成"}'

构建与验证

.\build.ps1
python -m unittest discover -s tests -v
python -m compileall nvda-addon/globalPlugins

默认产物为 dist/nvdaHttpBridge-1.4.0.nvda-addon。
